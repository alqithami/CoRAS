# Repository replacement notes

This repository-ready package synchronizes the public code and supplementary artifacts with the CoRAS manuscript and supplementary material.

It intentionally excludes raw datasets, local `.npz` exports, model checkpoints, and large prediction-set dumps. Public data are fetched through the scripts described in `REPRODUCE.md` and `DATA_LICENSES_AND_SOURCES.md`.

For anonymous review, do not link a personally identifying GitHub repository from the submitted manuscript. Upload the anonymized supplementary ZIP through OpenReview instead, or mirror this content to an anonymous review repository.
