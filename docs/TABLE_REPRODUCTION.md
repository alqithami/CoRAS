# Table Reproduction

The included `../results/` directory contains aggregate CSV and TeX files used for the reported tables. These files can be inspected directly or regenerated by rerunning the corresponding experiment suites and aggregation scripts.

Representative files:

- `../results/sim_complete/aggregate/main_table_alpha010.csv`
- `../results/pusht_paper_k64/paper_grade_aggregate/paper_main_table_alpha0.10.csv`
- `../results/droid100_paper_k64/paper_grade_aggregate/paper_main_table_alpha0.10.csv`
- `../results/autoeval_online_k32/paper_grade_aggregate/paper_main_table_alpha0.10.csv`

The generated configuration files are in `configs/generated/`.
